## Project overview

**#FollowtheMoneyCO** is a [Datasette](https://datasette.io/)-powered site exposing Colorado campaign finance data from the Secretary of State's TRACER system. It runs Datasette 0.64.8 (installed globally at `/usr/local/bin/datasette`).

- GitHub: `sandrafish/followthemoneyco26`
- Deployed to Google Cloud and published at [this URL](https://followingthemoneyco.com/).

## Running the site locally

```bash
datasette camp_fin_2026.db --metadata metadata.json --template-dir templates --plugins-dir plugins
```

## Architecture

### Data flow
Raw TRACER bulk CSV downloads → cleaned with Python/Pandas/Jupyter Lab → CSVs in `csvs/` → loaded into `camp_fin_2026.db` (SQLite). The database is **not** generated by code in this repo; it's updated manually when new TRACER data is available.

### CSV naming convention
- `_cont` suffix = contributions table
- `_exp` suffix = expenditures table
- Prefixes: `house`, `senate`, `state` (statewide), `issue_comm`, `super_pacs`, `trad_pacs`, `cand_loans`

### Key files
- `camp_fin_2026.db` — the SQLite database served by Datasette
- `metadata.json` — Datasette title, description, license, source, and plugin config
- `plugins/full_tables.py` — Datasette plugin that injects `all_databases_with_tables` into the index template, so the homepage can list every table across all databases
- `templates/index.html` — custom homepage (extends Datasette base; uses `all_databases_with_tables` from the plugin)
- `templates/pages/about.html`, `templates/pages/sql.html` — static info pages

### Plugins configured
- `datasette-block-robots` (via `metadata.json`) — blocks all robots except on the index page

## Deployment

Push to Google Cloud to deploy:
```bash
datasette publish cloudrun camp_fin_2026.db --service=followthemoneyco --plugins-dir=plugins --template-dir=templates
```
